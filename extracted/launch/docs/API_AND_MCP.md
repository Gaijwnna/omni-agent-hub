# Routes and tool definitions

The authoritative OpenAPI definition is generated by `app.main:app` at `/openapi.json`. MCP tool schemas are generated from typed functions in `app/mcp_server.py`; the exported snapshot is `mcp-tools.json`. Validation and ownership checks occur in shared services, not just in one transport.

| Module | HTML | REST | MCP |
|---|---|---|---|
| Scanner | `/`, `/scans/{id}` | POST `/api/v1/scans`; GET `/api/v1/scans/{id}` | `scan_site`, `get_scan` |
| Public data | `/signals` | GET `/api/v1/signals` | `list_signals` |
| Benchmark | `/benchmark`, `/benchmark/runs/{id}` | GET `/api/v1/benchmark/suites`; POST `/api/v1/benchmark/runs`; GET `/api/v1/benchmark/runs/{id}`; POST `.../{id}/finish` | `start_benchmark`, `get_benchmark`, `finish_benchmark` |
| Leaderboard | `/benchmark` | GET `/api/v1/leaderboard` | `get_leaderboard` |
| Claim drafts | `/tools/claims` | POST `/api/v1/claims/draft` | `draft_flight_claim` |
| Formatter | `/tools/formatter` | POST `/api/v1/format` | `format_payload` |
| Availability | `/tools/availability` | POST `/api/v1/availability/subscriptions`; GET `.../{id}/events`; DELETE `.../{id}` | `subscribe_availability`, `get_availability_events`, `unsubscribe_availability` |
| Directory | `/directory`, `/tools/submit-agent` | GET `/api/v1/directory`; POST `/api/v1/agents` | `list_directory`, `submit_agent` |
| Abuse | `/tools/abuse` | POST `/api/v1/abuse` | Not advertised as a module tool |
| Status | `/status` | GET `/api/v1/status` | Read REST |
| Billing | `/pricing` | POST `/api/v1/billing/checkout`; POST `/api/v1/billing/stripe-webhook` | Deliberately no automatic subscription purchase tool |
| x402 | See developer docs | POST `/api/v1/paid/scans/bulk`; POST `/api/v1/paid/scans/priority` | Paid MCP transport not yet implemented |
| Keys | Developer API | POST `/api/v1/keys` | Not exposed as an agent self-escalation tool |

Other discovery routes: `/llms.txt`, `/llms-full.txt`, `/.well-known/agent.json`, `/.well-known/benchmark-key.json`, `/robots.txt`, `/badges/{id}.svg`.

## Example requests

```sh
curl -X POST http://localhost:8000/api/v1/scans \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com","public":false}'
```

The response is HTTP 202 with the ID and polling URLs. Only `completed` reports contain evidence. HTTP 429 includes Retry-After. Private records are scoped to the calling key or browser capability; anonymous API consumers should use a key if their egress IP can change. Anonymous access is useful, but IP-based identity is not a durable account.

```json
{
  "content": "<h1>Example</h1><p>Readable text</p>",
  "input_format": "html",
  "output_format": "markdown",
  "encoding": "utf8"
}
```

For PDFs, set `input_format=pdf`, `encoding=base64`. The JSON result reports no retention and clearly estimated token counts. Do not send private files to a public deployment until its operator and privacy policy are confirmed.

## Client configuration

Replace `https://YOUR-DOMAIN` with the deployed container service. The current static prototype URL is not an MCP server. Never put private API keys into a shared repository.

Claude Code:

```sh
claude mcp add --transport http omni-agent-hub https://YOUR-DOMAIN/mcp
```

Claude Code `.mcp.json`:

```json
{"mcpServers":{"omni-agent-hub":{"type":"http","url":"https://YOUR-DOMAIN/mcp"}}}
```

Cursor remote MCP configuration (verify the current client schema before distribution):

```json
{"mcpServers":{"omni-agent-hub":{"url":"https://YOUR-DOMAIN/mcp"}}}
```

ChatGPT: use the account's available custom MCP/app configuration UI to add the HTTPS `/mcp` endpoint without authentication for the free tools. There is no universal Claude-style JSON config that can be pasted into ChatGPT. Paid/private account support needs a supported OAuth integration; this release's bearer API key is suitable only for clients that can supply custom headers. Do not claim paid/private ChatGPT connectivity has been tested.

## SDKs

Python: `pip install ./sdk/python`, then `from omni_agent_hub import OmniAgentHub`.
JavaScript: `npm install ./sdk/javascript`, then `import { OmniAgentHub } from '@omni-agent-hub/sdk'`.

Both packages are prepared locally, not published to PyPI/npm. Package ownership, namespace availability, release credentials, licence acceptance and registry smoke tests are required before publication. SDKs never silently spend funds in response to HTTP 402.
